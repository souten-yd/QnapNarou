# QnapNarou

QTS 5.x packaging and integration project for [narou.rs](https://github.com/Rumia-Channel/narou.rs).

Development takes place on milestone pull requests. The original narou.rs project is credited and remains the upstream source; bundled third-party code and binary distributions must retain the corresponding notices and licenses.

See milestone pull requests for implementation status. No installable QPKG is published yet.
